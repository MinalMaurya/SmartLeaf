# 🌿 SmartLeaf

SmartLeaf is an AI-assisted Android application developed to help farmers and plant enthusiasts identify plant diseases through image-based analysis. The application combines machine learning, weather insights, and AI-generated explanations to provide users with information about plant health and possible remedies.

## 📱 Features

### 🔍 Plant Disease Detection
- Capture or upload a plant leaf image.
- Analyze plant diseases using TensorFlow Lite models.
- Display disease predictions with explanations.

### 🤖 AI-Powered Explanations
- Generates disease descriptions using Gemini AI.
- Suggests possible causes and remedies.
- Provides easy-to-understand information for users.

### 🌦️ Weather Information
- Displays weather data for the previous 7 days.
- Shows weather forecasts for the next 7 days.
- Powered by Open-Meteo API.

### 💬 Smart Chatbot
- FAQ-based chatbot for common agriculture-related questions.
- Quick responses for plant care and farming queries.

### 🌐 Language Support
Currently available in:
- English
- Hindi
- Marathi

### 👤 User Features
- User Registration and Login
- Profile Management
- Disease Scan History

## 🎯 Project Objective

The goal of SmartLeaf is to assist users in identifying plant diseases and understanding possible treatments through AI-assisted analysis. The project aims to make plant health information more accessible and easier to understand.
